PDF Chrome Spec — build law
i. Page-1 title: line starting "# " → Helvetica Bold 16.
ii. Subtitle: exact line "CodeBreaker System Architecture Blueprint" → Helvetica Italic 9 directly under title.
iii. Section headers ("## ") → Helvetica Bold 12.
iv. Body lines → Helvetica 10, multi_cell(0, 5.5, ...), x reset to l_margin after every cell.
v. Folder-structure lines (between "## Folder Structure" and next "## ") → Courier 9.
vi. Footer is NOT a content line. After the content loop: 1. If last page empty (get_y() <= t_margin + 5 and page_no() > 1): delete_page(). 2. set_auto_page_break(auto=False) — content margin stays 18, reserving the bottom band. 3. set_y(h - 12); set_font("Helvetica", "I", 8). 4. One line: "Generated by CodeBreaker Workspace + DD-MM-YYYY" (single spaces around +).
vii. Footer hugs the true bottom of the LAST content page. Never a blank page. Never mid-content. Never glued to the date.
